# 01: Demo authentication and application shell

**What to build:** A visitor can sign in with fixed user or admin demo accounts and reach the appropriate role-specific application area.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The application presents clearly labeled user and admin demo accounts.
- [ ] Signing in as the user opens the user-facing dashboard shell.
- [ ] Signing in as the admin opens the admin monitoring shell.
- [ ] The active role is visible and the user can sign out or return to login.
- [ ] Demo authentication is visibly identified as mock behavior.
